# CaicoLeung/homebrew-tap

Homebrew tap for [dag-tickets](https://github.com/CaicoLeung/dag-tickets) and
related tooling.

## Install

```bash
brew tap CaicoLeung/tap
brew install dag-tickets
```

Upgrade with the usual `brew upgrade dag-tickets`. The `Formula/dag-tickets.rb`
is regenerated automatically by the dag-tickets release workflow on each tagged
release, so this tap always tracks the latest published version.
